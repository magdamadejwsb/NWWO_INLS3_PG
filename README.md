## Cel projektu
Głównym celem trojektu jest nauka systemuy kontroili wersji Git oraz praca na platformie GitHub. Cele szczegółowe to:
- współpraca w repozytorium GitHub,
- tworzenie i zarządzanie gałęziami,
- korzystanie z Pull Request,
- zarządznie zadaniami przez Issues,
- rozwiązywanie konfliktów podczas scalania zmian.

## Wymagania systemowe
Do uruchomienia projektu **wymagane są**:
- Python w wersji 3.12 lub nowszy
- Git
- Terminal
- Edytor kodu, np. Visual Studio Code

Sprawdzanie wersji Pythona:
```
bash
python --version
```
Sprawdzanie wersji Gita:
```
bash
git --version
```

## Uruchamianie projektu
Aby uruchomić aplikację należy skolonować repozytorium i uruchomić główny plik aplikacji:
```
bash
python main.py
```
